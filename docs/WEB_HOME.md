`/` 是首页，`/mplus.html` 是大秘境生成器。首页借鉴用户提供的CoolPlan、KeystoneLoot和Lorrgs的工具入口思路，使用已认可的冷蓝与石墨灰风格。当前可用入口只有大秘境首领方案；更多工具是标明期待的非交互区域，后续按实际功能添加入口。没有伪造使用量、排名、记录或未实现能力。

生成器沿用专精图标／职责、副本导航、首领头像列表，全部新草稿仍为空白。后续提醒改成卡片内完整的一行开关，标题“之后每次冷却结束，都提醒我”，说明只有按这条提醒实际使用一次技能之后才开始后续提示；每次冷却结束显示提醒，语音跟随游戏内开关。只允许第一次事件的技能行，不适用时明确显示原因并禁用。协议仍是after:ready，没有改游戏冷却判断。

Lorrgs和CoolPlan的链接及用途只放在两页页脚。团本复制MRT／NSRT进插件；CoolPlan作为大秘境技能安排参考。本站继续只做手动首领配置和字符串生成。

`drafts.mjs`拥有草稿存储的兼容读取／保存：保留nr-dungeon旧键与nr-plan迁移，不删除旧记录；完整验证后才保存；读取失败返回空草稿，保存失败明确报错。最近专精／副本使用nr-last-context，仅存公共选择。planner.mjs拥有UI、本页草稿和生成快照；input立即使导出失效，切首领保留配置，切专精／副本及离开页面时沿用未保存提醒。没有把旧原型的示例或内存缓存接成默认个人策略。

图标由ImageGen生成，最终冷蓝圆管N图标及提示词见BRAND_ASSET。当前图片目录来自已有设计原型的公开游戏图像快照；原型保留历史，不作为新首页。新增网页图像必须进入源码包，build.py已加入图片扩展名。
