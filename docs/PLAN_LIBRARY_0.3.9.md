# 0.3.9-dev：重复预览与方案删除

2026-10-24。只交付本地 TMN-发布，不安装游戏、不发布网站插件下载。

同专精、同首领、同难度、同格式重复导入仍覆盖原方案。修复导入预览和已保存方案重复列出的问题：内容相同时直接显示已保存项；修改后的未保存预览替代列表中的对应项，不改存档。

NSRT／MRT、网站事件方案、网站时间轴仍为独立格式，可在方案回放列表选中旧方案，点击「删除所选方案」，再次点击确认。删除只影响所选格式和当前专精，不删除其他首领。新增「撤销删除」，只保留最近一次删除，且不能覆盖后续新导入的方案。切换选择取消删除确认，战斗中不可删除。

注意：删除方案后，其他格式的同首领方案可能接管；史诗钥石启用了「未配置首领自动爆发提醒」时，也可能使用内置提醒。删除不等于关闭全部提醒。

验证：59 项 Lua 5.1 静态／MOCK 回归和 7 项时间轴集成测试；游戏内 UI 视觉、声音与实际点击仍待 LIVE 验证。
