# UI 逆向与重建记录

对象为用户已有 TimelineReminders v453 原包中提取的明文 Lua；本次只读既有文件，没有获取新版本。0.1.3 后续仍由 NextReminders 独立维护。

## 观察到的代码事实

- `LiquidUI/Settings.lua`：灰边框及半透明黑色控件底色。
- `LiquidUI/Widgets/Window.lua`：独立深蓝标题拖动条、上半渐变/下半纯色、关闭按钮；默认按钮18像素、标题条22像素。
- `LiquidUI/Widgets/Button.lua`：自建 Button，默认26像素高度，独立字体、背景、边框和鼠标悬停，显式启用/禁用。
- `LiquidUI/Widgets/EditBox.lua`：隐藏原生三段输入框纹理，自画背景和内边距。
- `Interface/Interface.lua`：主窗口默认宽1200；`Interface/Timeline/Timeline.lua`：轨道24像素、间隔2像素、10秒网格、绿色模拟游标和提醒图标轨道。

这些是静态代码证据，未打开原插件运行界面，不能称为原界面截图或完整交互逆向。已有源码足以判断上述结构，无需再次初始化 REA 或执行原插件。

## 独立实现选择

参考自建控件、标题栏、统一密度和轨道显示的组织方式，以我们自己的 Lua 重写 Theme。没有复制 LiquidUI 文件、字体、图标或其他媒体。选择石墨底色和青色强调，降低长窗口的拥挤感。

导入和提醒设置分页，导入文本/方案检查两栏，独立滚动阶段绑定；保存和播放按钮明确分开。播放窗口使用时间列、游戏技能图标、阶段列和状态列，上方轨道表示已知提醒时点与模拟当前位置。仅未知阶段等待用户手动演练，不猜测实时机制。

## 预览与验证

`docs/ui-preview.html` 是按当前主题与布局制作的交互视觉样稿，不运行游戏 Lua，也不含游戏声音/团框实现。`ui-import.png`、`ui-settings.png`、`ui-playback.png` 是本地浏览器样稿截图，已逐页检查文字与间距；浏览器字体、符号图标和滚动行为与游戏不同。

MOCK 运行真实 Lua：两页切换保持导入草稿、保存设置经原校验且战斗拒绝、导入保存/播放生命周期回归、9个阶段绑定滚动、500行控件复用。LIVE 未测：实际字体/缩放、输入焦点、滚动条、原生技能图标、标题栏拖动、按钮点击区域和团框显示。
