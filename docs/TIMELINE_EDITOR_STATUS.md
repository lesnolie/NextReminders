# 团本时间轴首个闭环

日期：2026-10-23。开发目录：`C:/work/NextReminders`。

## 使用

运行 `python tools/web_server.py --port 56717`，打开 `http://127.0.0.1:56717/raid.html`。
粘贴 Lorrgs NSRT，输入个人专精编号，导入。未知来源阶段要填写开战后的起点，也可直接手填该技能的绝对时间。
时间轴按预计区域建议绑定，默认明确使用固定兜底；手动选实时阶段需 BigWigs，LIVE 未测。
拖动或修改后可撤销/重做。导出 NRPlan:3，在游戏 `/nr` 检查、保存或脱战预览。

## 时点语义

- `start`：开战一次，偏移为开战后秒数。
- `stage:p2.5` 等：大阶段开始；与 NSRT 原始 `ph` 独立，原始字段完整留在 source 中。
- `mechanic:rage`：被缚之怒读条开始；`mechanic:heart`：心脏易伤开始。当前仅固定参考，不宣称实时识别。
- `occurrence`：明确第几次；Lua 调度也测试了阶段 every。网页首个版本使用明确次数。
- `offset`：相对锚点秒数。`fallback`：最终提醒的开战后绝对秒数，已经包含偏移，不能再次相加。
- `timing:fixed` 明确采用兜底；`signal` 等待已接入信号，不接受负偏移；`predicted` 只接受声明已接入的预测源。当前心脏没有预测适配器，不能导出 predicted。
- 预测/实测覆盖只做了人工事件模拟测试，不代表游戏中机制已识别。
